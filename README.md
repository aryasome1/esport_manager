# eSports MOBA Manager - Mobile Legends Division System

## Project Overview
A comprehensive eSports management simulation game inspired by Mobile Legends, featuring competitive team management, hero drafting, and player development systems.

## Architecture
- **Frontend**: Expo Go (React Native)
- **Backend**: Python (FastAPI + SQLAlchemy + PostgreSQL)
- **Real-time Communication**: WebSocket
- **Authentication**: JWT

## Key Features
- 5v5 MOBA team composition with role-based gameplay
- Hero assignment and lane preference system
- Draft and ban mechanics (3 bans per team)
- Player attribute management (OVR, Hero Power, Focus, Mental, Fatigue)
- Hero Power development through training
- Coach dynamics and strategic influence
- Real-time draft phase visualization
